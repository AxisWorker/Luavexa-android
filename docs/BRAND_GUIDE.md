# Luavexa — Brand guide v1

> **Create • Script • Build**

## Identity

Luavexa is the name of this independent mobile-first development project. **Luavexa Android** is its Android app and repository edition. Use **Luavexa** as the visible app name. The Rust crate names and Android package identifier are preserved until a separately tested migration.

## Palette

| Token | Hex | Usage |
| --- | --- | --- |
| Midnight | `#0B1025` | Main background |
| Panel | `#151B3E` | Cards and panels |
| Electric cyan | `#00D9F5` | Accents and controls |
| Aurora purple | `#8A49F7` | Creative and AI highlights |
| Sky blue | `#4F72FF` | Secondary emphasis |
| Ice | `#E8EDFF` | Primary text |
| Muted | `#9DACCE` | Secondary text |

## Project boundaries

Luavexa is built on [rustudio](https://github.com/rippelz/rustudio) and the [Android fork](https://github.com/TouseefX/rustudio-android). Retain upstream MIT / Apache-2.0 license notices and third-party notices. Do not present the planned AI integrations as shipped features before they are tested. Luavexa is not affiliated with Roblox Corporation.
